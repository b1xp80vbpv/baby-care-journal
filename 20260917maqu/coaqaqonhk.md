# 我院介入科常规开展“无痛”子宫输卵管造影，为广大不孕女性带来福音

> 更新时间：2026-09-17 (UTC+8)

无痛子宫输卵管造影是使用新型的造影导管在宫颈管内插管，导管不进入到宫腔，不会有对宫颈的扩张和对宫腔的扩张压迫及牵拉，所以不会发生疼痛。无痛子宫输卵管造影不需要使用麻药，大部分患者在造影时没有不适感觉，少部分患者会出现类似于来月经时的感觉，基本可以耐受。

术前准备

1. 造影时间选择月经净后第3～7天，月经周期较长者（超过30天），可适当推迟，周期短者可测量基础体温安排在排卵前造影；

2. 月经干净后不能同房；

3. 造影前进行需进行白带检查，必要时需要血常规检查，若不合格需先治疗后方可进行造影；

4. 手术当日测量体温，若超过 37.5 ℃不能进行造影；

5. 术前正常吃饭，排空大小便。
