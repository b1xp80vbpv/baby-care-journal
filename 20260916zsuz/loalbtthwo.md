# 超长三伏期，吃对“三瓜三豆三茶”，健康安然度夏

> 更新时间：2026-09-16 (UTC+8)

**三瓜三豆三茶**

本周杭城再次启动高温模式，局部地区气温达到40度以上。

高温酷暑难耐，饮食调整至关重要。

杭州市第一人民医院营养科营养师林朝红推荐夏日消暑“三宝”——“三瓜三豆三茶”，既确保营养摄入，又能消暑降温。

01

三瓜

瓜类，清淡可口，能够清热化湿，排毒排湿，最适合夏季食用。

苦瓜

**食用价值：**苦瓜味苦性凉，有利于消化，可清热泻火祛暑，算得上炎夏第一瓜。苦瓜富含维生素C、维生素B、膳食纤维等，具有清热去火、解毒明目的功效。

不仅如此，苦瓜热量低，还有助于减重；其所含的苦瓜皂苷有类似胰岛素的作用，有明显的降血糖作用；苦瓜还能泄去心中烦热，排出体内毒素，增强皮层活力，使皮肤变得细嫩健美。

**食用贴士：**一般人都可食用，癌症、糖尿病、青春痘患者以及肥胖者尤为适宜（肥胖者最好生吃）。但苦瓜性凉，脾胃虚寒者应慎食或少食。夏天天气炎热，适量吃苦味大有益处。苦瓜吃法多样，煎、煸、炒、蒸、凉拌等均可。不习惯吃苦瓜的人，可以用开水焯一下，能去除苦味。

丝瓜

**食用价值：**丝瓜，性味苦甘，清凉微寒，具有清热化痰、凉血解毒、解暑除烦的功效。丝瓜富含B族维生素、维生素C，其所含的皂苷和黏液有利于大便通畅，能预防便秘，帮助提升新陈代谢。

**食用贴士：**要注意，苦味丝瓜含有带苦味的葫芦素（碱糖甙毒素），误食会引发急性中毒症状，例如上吐下泻、消化道出血、肝肾功能损害等，严重时甚至会导致死亡。因此，吃丝瓜时如发现有苦味，应该果断扔掉，并把用过的菜刀和锅清洗消毒。

冬瓜

**食用价值：**冬瓜富含维生素C、钾、膳食纤维等营养成分，冬瓜味甘、性寒，有清热利水、消肿祛湿的功效。

冬瓜是典型的高钾低钠食材，有助于控制血压。冬瓜不含脂肪，热量低，饱腹感强，而且富含维生素C，很适合减肥人士和爱美的女性食用。

**食用贴士：**冬瓜全身都是宝，冬瓜皮利水消肿，冬瓜瓤清心除烦。红糖腌制冬瓜皮和冬瓜瓤，锅中烧水，放入冬瓜皮瓤和玫瑰煮5分钟，最后加入两片柠檬即成。一杯夏日冬瓜茶就完成了。

02

三豆

民间有“夏吃豆，胜吃肉”的说法。豆类，既能健脾祛湿，又可清热解暑，还能调养内脏，是夏至好选择。这里主推三种豆类。

毛豆

**食用价值：**毛豆即新鲜带荚的黄豆。它营养全面，富含优质蛋白质、B族维生素、微量元素（铁、钙、钾等），且含有微量生物活性物质，尤其是被称为“天然植物雌激素”的大豆异黄酮。另外，毛豆维生素C含量丰富，约为黄豆芽的两倍；毛豆的钾含量也非常丰富，高达478mg/100g，是香蕉的2倍，鸡蛋的5倍，有助于稳定血压、保护心血管。

**食用贴士：**消化不良的人群，毛豆中含有较多的植物纤维，这些成分少则有益，食用较多的情况下，容易增加肠胃的消化负担，出现腹胀，胀气等情况。

痛风人士、高尿酸人士，要注意食物中嘌呤的含量。毛豆中，每百克中约含有嘌呤27毫克，同时富含钾元素等成分，所以根据个人情况最好适量少吃。

易过敏体质，对蛋白质过敏的人士，最好慎重食用，以免出现红肿，皮肤痒等不适。

绿豆

**食用价值：**在中医上它更是药食两用的食材，有清热解毒、消暑生津、利水消肿的功效，富含钾、磷等矿物元素。在这酷热的天气里特别高温环境工作的人出汗多，钾流失多，喝绿豆汤可以补充身体的水分和矿物质，达到清暑益气的效果。

**食用贴士：**绿豆汤偏寒凉，身体虚弱、脾胃虚弱、拉稀、胃脘疼痛的人建议少喝绿豆汤。

**糖尿病患者** 绿豆血糖生成指数（GI）只有27属于低GI食物，血糖稳定时，还是可以喝一小碗的，记得不要加糖呦！

**高血压患者** 绿豆中富含钾，钾具有扩张血管,对抗钠的升压作用。

**肾病患者 **绿豆属植物蛋白，富含磷、钾，因此肾病的患者需要控制摄入。

豌豆

**食用价值：**豌豆味甘性平，归脾、胃经，具有食用价值及药用价值。其鲜种子、嫩尖、嫩荚均可作为蔬菜食用。豌豆的蛋白质含量在蔬菜中算是佼佼者， 豌豆蛋白具有良好的氨基酸组成配比，消化率高。

豌豆含有大量的膳食纤维，有助于促进肠道蠕动，预防便秘，并可以降低患肠道疾病的风险。豌豆中富含蛋白质、维生素B群、维生素C、维生素K等维生素，以及钾、铁、锌等矿物质，有助于维持身体正常功能，增强免疫力。豌豆中富含的多种维生素和矿物质，有助于维持正常血压水平，促进血液循环，从而减少患心脏病的风险。

**食用贴士：**在营养成分上，豌豆既能当菜，又能当饭。带荚鲜豌豆的碳水化合物含量在蔬菜中可不算低为 21.2g/100g，热量为 111kcal/100g；煮豌豆的碳水化合物含量为 19.2g/100g，热量为 107kcal/100g。二者的碳水化合物含量和热量都比土豆还高，建议大家当做主食对待。糖尿病患者应注意适量食用。

豌豆中含有一定的植物凝集素和蛋白酶抑制剂，烹饪时应充分煮熟，以消除这些抗营养因子。

对豌豆过敏的人应避免食用。部分有蚕豆病病史的人，对豌豆也存在交叉过敏的反应，食用时应慎重。

消化不良和肾脏疾病的人不宜过量食用，以免引起不适。

夏季食养原则

夏季食养应遵循饮食清淡、多食酸苦、少食生冷、解暑化湿、卫生饮食的原则。

1.适量食用苦味的食物，如苦瓜、苦苣等，其中多含生物碱，可起到补气固肾、健脾除湿的功效，切记不能多吃，可能会影响食欲。

2.适量摄取酸味食物、高纤蔬果，夏季饮食以甘寒、清淡为宜，烹煮忌重油厚味。适当吃酸味食物，如番茄、柠檬、乌梅、葡萄等，不但能够生津止渴, 使人脾胃大开，还可以抑制微生物繁殖，有极佳的杀菌功效。

3.凉性蔬菜宜多食。因此应适当多食些凉性蔬菜如苦瓜、丝瓜、黄瓜、菜瓜、番茄、茄子、芹菜、生菜、芦笋、凉薯等，有利于生津止渴、除烦解暑、清热泄水、排毒通便。

4.过食生冷不可取，夏季注意饮食卫生。夏季的食品容易腐败变质，蔬菜一定要洗干净，剔去枯黄、有虫点的，特别要注意夏季的饮食卫生。

5.夏季饮食忌“水果化”。天气炎热，食欲不振，很多人都喜欢多吃水果以补充营养。吃水果虽能摄取大量的维生素和水分，但可能会忽视其他营养的均衡摄入，因此，吃水果要适度。

03

三茶

入夏以来，杭州市第一人民医院互联网医院陆续推出十几种中药茶饮，深受市民们的追捧。这里主要推荐三种中药茶饮。

“好喝的凉茶”

此款凉茶由罗汉果、麦冬、玉竹、玫瑰花、佛手等组成，兼顾了效用、口感和颜值，清凉又不伤胃，解暑又祛烦闷，还“兼职”养颜。一经推出，受到市民喜爱。在这款凉茶中你真的可以看得到有一整颗的罗汉果。

桑菊清火饮

夏季要清热解毒、祛火，还要除暑湿。桑菊清火饮内含菊花、金银花、桑叶等，能清热凉血、清心利尿。用于风火热毒所致口舌生疮、心烦失眠、小便黄赤、眼红充血等。

酸梅减脂汤

这款汤剂乌梅配甘草，能起到酸甘化阴的作用，能够生津补液，最适合夏季易出汗伤津之时引用，山楂、陈皮健胃消食，荷叶清暑化湿，炒决明子清热通便，适合暑湿所致头身困重、烦闷、口干黏腻、乏味，舌苔厚腻人群。
