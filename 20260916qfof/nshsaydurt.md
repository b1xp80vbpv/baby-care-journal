# 援沪日记系列【二】

> 更新时间：2026-09-16 (UTC+8)

吉安市妇幼保健院两批援沪医疗队已经陆续抵沪，有序开展各项援护抗疫工作。援沪医疗队的生活非常忙碌，但又充满点点星光，队员们用日记，讲述抗疫一线最平凡又最感人的故事，带我们“走进”方舱，“到达”战役前线。

**【一】党员应白衣做铠甲，挺身而出、冲在前线**

**记录人：吉安市妇幼保健院第二批援沪队 队长  张小芳**

**时间：2022年4月18日**

**地点：上海**

这是我第二次参加援助任务，第一次是2014参加为期2年的援助突尼斯。武汉战疫，没有机会参与其中，心中有些遗憾。此次上海疫情越发严峻，听闻需要一名妇产科医生，我立刻毫不犹豫地递交了请战书。作为医者，应时刻谨记“不畏艰辛、甘于奉献、救死扶伤、大爱无疆”精神;面对疫情，党员应白衣做铠甲，挺身而出、冲在前线。

我爱人听闻我的决定，对我说：“亲爱的，放心去战疫吧，家里有我呢!”他一直是我我坚强的后盾，让我无后顾之忧，让我在行医路上一往无前!女儿说：“妈妈，您放心，我会好好学习的!我的妈妈是抗疫战士，我很自豪!”带着强烈的使命感和责任感，在领导的亲切关心和千叮万嘱下，我们踏上抗疫征程。

疫情笼罩的上海，见不到往日的热闹与喧哗。为了让上海尽快走出疫情的阴霾，哪里需要我们，我们就去哪里，先是战斗在上海疫情最严重的浦东区，在封控区采核酸，得到了封控区居民们的点赞和肯定!让我们内心倍感温暖，同时也感到更加责任重大。继而转战浦东区源深方舱，方舱是由写字楼改造，病区10层楼，总共有3300多张床位，目前已入住2300多病人，我们工作人员共90人，每6小时一班，每班次8个人，工作特别的繁忙。

（为了防止感染，剃光发鬓）

（为了避免感染，数十上百遍地练习，穿脱防护服，直到深夜。）

今天我是下午两点到晚上八点的班，上午八点我就在舱外帮忙，处理出舱患者解离信息，协助领取物资。下午两点，我入舱后，一批批的患者被公交车送来，患者中最小的5岁，最年长的85岁拄着拐杖的老爷爷，他们中有不少人情绪不稳定，很焦虑。我们用贴心的服务、亲切的话语、耐心的安慰他们，帮助他们树立信心。6个小时我们收治了近120名患者，病区里还不停的传来：xx床病人发热39度多，xx床病人咽痛不适，xx床女孩痛经等等呼叫，虽然厚重的防护服、护目镜下的雾气、面屏上的水汽、勒紧的口罩，让我们不那么灵活，但我们知道大家需要我们，我们不停的在病区中穿梭，患者们举起大拇指点赞和一句句感谢的话语，让我们内心充满力量。

在这个援沪抗疫吉安大家庭中，所有的人都坚守援沪初心，用实际行动证明我们的抗疫决心，我们终将不辱使命，继承发扬老区人民的井冈山精神，为上海疫情防控贡献一份吉安力量。

**【二】“云祝福”：女儿生日快乐**

**记录人：吉安市妇幼保健院第二批援沪队  程雪**

**时间：2022年4月18日**

**地点：上海**

新一轮疫情为整个上海按下了“暂停键”，同时也为我们按下“加速键”。4月12日，我成为吉安市妇幼保健院第二批援沪医疗队的一员，紧急驰援上海。

4月18日是我女儿11岁生日，这是她出生以来，我第一次不在她身边陪她过生日。晚上，我在千里之外的“疫”区为她过了一个“云生日”。视频中，女儿懂事地安慰我：不要介怀未能亲自陪伴的遗憾，还一直叮嘱我在疫情一线要好好保护自己。

挂断电话，我又将披上“战甲”，赶往“战场”。我看着手中临行前女儿送给我的祝福字条，亲爱的宝贝，我想对你说：因为有你们的支持，抗疫期间我不管多苦多累，一切都是值得的。因为无畏，我们这个社会才会弥漫奉献的芬芳;因为担当，我们的国家才有岁月静好;因为理解，我们才会逆行，负重前行。亲爱的宝贝，记住这个特殊的生日，记住这场疫情，更要记住在这场疫情中所有最美逆行者。无论何时，都要学会感恩，懂得奉献。

愿疫情早日结束，愿美丽的大上海早日恢复往日的喧嚣!

上海加油!中国加油!!

**【三】作为一名共产党员，参加抗疫我义不容辞**

**记录人：吉安市妇幼保健院第二批援沪队 李珊珊**

**时间：2022年4月21日**

**地点：上海**

四月的上海，深夜依然有些凉，坐上送我们去方舱的大巴车，准备去接凌晨两点的班。深夜的陆家嘴，如此安静，可方舱值班的工作人员却依然忙碌着，有的在准备早上需要的防疫物质，有的在一个个病房楼道做好消毒工作，还有的在准备隔离人员早餐的配送。大家都各司其职，一切进行的都那么井然有序。

作为一名共产党员，参加抗疫我义不容辞，作为一名护士，能加入援沪医疗队我觉得特别光荣。这个世界，本就没有什么岁月静好，只是有人在为我们负重前行。愿山河无恙，你我都安康，加油，上海…

**【四】一句“谢谢吉安”，让我觉得付出值得**

**记录人：吉安市妇幼保健院第二批援沪队 黄莹**

**时间：2022年4月19日**

**地点：上海**

今天是我在源深方舱的第一个晚班，也是我援“沪”第八天。

虽说有援“饶”的经历，面对方舱医院内心依然忐忑，担心工作不能完全做好。提前一小时从驻地出发，经过严密防护，外层衣服标记地方、姓名，20:00准时到岗交接。首先映入眼帘的是一辆辆满载的大巴，面对一双双焦虑的眼睛，真切感受到此地疫情的严峻性和任务的艰巨性。即便内心有所波澜，望着无数期盼的眼神和忙碌的“大白”们，心态稍做调整，快速投入工作中。

正被左右“围堵”之时，一位六十多岁的大叔多次轻拍我的肩膀，抖动的双手拿着手机小声地问着：“大白，能帮我们看看怎么办理入舱手续吗?我不会操作。”一抬眼就瞧见两位颤颤巍巍年近九十岁的老人，原来是大叔的父母，瞬间我破防了，强忍着眼眶里打转的眼泪，仔细询问信息顺利办理了入舱手续。临别时，大叔激动的说：“谢谢你!谢谢吉安!”

疫情当前，有幸是一名医护人员，在危机时刻能尽点绵薄之力。援“沪”的日子虽然辛苦，一句“谢谢吉安”，让我觉得付出值得!愿疫情早日结束，山河无恙，人间皆安!上海加油!

**【五】**

**记录人：吉安市妇幼保健院第一批援沪队 队长 叶祥燕**

**时间：2022年4月18日**

**地点：上海**

我们接到了正式进入新国际博览中心方舱医院N4舱的任务，在进舱前，院感老师组织我们在酒店再次培训穿脱防护服，还有人员准备帮我们剃头发，并做好一些物质的准备。我被任命为第五小组的组长，负责先进舱熟悉环境、病人数和出入院的流程等等。

进入方舱病区，我们小组接管的是N4病区的c1，c2病区，5个护士管220张床，c1c2已经是满床的状态，我们需要了解病人要做哪些治疗、哪些病人是特殊人群需要特别关注、需要每一小时拿上对讲机巡视病房。在我巡视病房的时看到在有个小男孩没有陪护人，正在认真地看《父与子》这一本书，他告诉我：这已经是他进入方舱第四天了，他特别喜欢这套书，打算在这里把这本书看完，享受书本带给他的快乐。

每完成一天的工作后，我们都要经过严格的出舱消杀，两两一组进行消杀，等一个班次所有的队员都完成消杀走出医院，往往都已经是两个小时以后了。出舱后，大家看到彼此脸上口罩的压痕，忍不住对视而笑。虽然每天工作都很辛苦，可是没有人喊累，也没有人抱怨，因为我们心中有一个明确的目标，那就是战胜病情，早日回家。

**【六】我也想入党**

我们始终坚信，伟大的抗疫精神定会让上海这座美丽的城市重新焕发新的时代活力!或许青春不常在，但热血亦难凉，我们总相信胜利就在前方!
